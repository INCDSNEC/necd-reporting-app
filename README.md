# NECD Reporting

Aplicație statică de raportare NECD Art. 9, cu importul fișierelor de laborator originale, introducere manuală și verificări tehnice QA/QC. Găzduită prin GitHub Pages.

Datele și șablonul sunt păstrate separat, în repository-ul privat `INCDSNEC/necd-reporting-data`. Acest repository public nu trebuie să conțină date sau tokenuri.
